# DSH Desktop Experience

面向 DeepSeek Harness 原生应用的本地插件。它只在 `DeepSeekHarness.exe` 提供桌面桥接时注册界面，不为外部浏览器创建插件页面；不修改 DSH 核心页面，也不使用哈希类名或 DOM 选择器，而是通过官方客户端插槽提供：

- “设置 → 插件”中的“桌面体验”“桌宠”“壁纸”三个独立入口；
- 顶部深色磨砂快捷栏：四个带名称的大号按钮切换侧边栏、收起详情、桌面桌宠和壁纸，两组之间有渐隐分隔线；
- “桌面桌宠”把同一个 `PetOverlay` 加载进不抢焦点的原生透明置顶窗口，可离开 DSH 自由移动、跨屏显示并记住位置；透明空白区域不会遮挡其他应用，不再加载或维护另一套桌宠 HTML 页面；
- 独立桌宠保留点击展开、余额分项、Token 用量、缓存写入与命中率、定时/手动刷新、右键菜单和主屏位置复位；显示器变化、系统唤醒或渲染异常后会自动找回并恢复；
- 静态/动态壁纸：安全收件箱、格式与资源限制、去元数据转码、减少动画模式静态封面；
- 所有设置只保存在本机 `workspace/.assistant/desktop-experience/config.json`。

## 壁纸使用

1. 在“设置 → 插件 → 壁纸”点击“从本地导入壁纸”，直接选择 `.png`、`.jpg`、`.jpeg`、`.webp` 或 `.gif`。也可把文件放入：

   `D:\path\to\deepseek-harness\workspace\assets\wallpapers\inbox`

2. 收件箱方式需要再点击“安全扫描并更换”；本地选择方式会自动进入同一套安全扫描和转码流程。

3. 原文件不会直接展示。插件会验证真实格式、文件大小、尺寸、帧数、总像素和动画时长，然后去除元数据并转成 WebP。动态图片另生成一张静态 PNG，在系统启用“减少动画”时自动使用。

安全限制：输入不超过 20 MiB、边长不超过 8000 px、单帧不超过 4000 万像素、动画不超过 300 帧和 60 秒、转码结果不超过 30 MiB。拒绝 SVG、HTML、远程 URL、data URI、视频、符号链接和路径穿越。

## 安装边界

本目录是源码，不应直接复制到 DSH profile。先打包，再用项目的 `security/Inspect-PluginPackage.ps1` 扫描；只有人工复核报告并明确批准后，才能通过 `security/Install-PluginSafely.ps1` 安装。
